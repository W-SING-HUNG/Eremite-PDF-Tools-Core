# Support

Report ordinary bugs and usage questions through
[GitHub Issues](https://github.com/W-SING-HUNG/Eremite-PDF-Tools-Core/issues). Read the [README](README.md)
and search existing issues first.

Include the Supplier version / commit, OS, Node.js version, external engine
versions, minimal reproduction, expected and actual behavior, and sanitized logs.
Use synthetic inputs. Do not attach secrets, private documents, proprietary
source files, production datasets or unsanitized input/output files.

This repository handles independently reproducible Supplier capability and
protocol bugs. Eremite UI, authorization, persistence, File Lifecycle, Run History
and Host integration questions belong in
[Eremite Issues](https://github.com/W-SING-HUNG/Eremite/issues).
If the affected layer is unclear, describe the observed behavior and reproduction.

Security issues must use this repository's
[Private Vulnerability Reporting](https://github.com/W-SING-HUNG/Eremite-PDF-Tools-Core/security/advisories/new),
following [SECURITY.md](SECURITY.md). Do not report sensitive details in public Issues.

No response SLA or resolution timeline is promised.
